# Обрезка MP3

Простая утилита в браузере: вырезает нужный фрагмент из MP3 и сохраняет отдельным файлом.

**Открыть онлайн:** https://simonovnikita9.github.io/mp3-cutter/

- **Без потери качества.** Звук не перекодируется: фрагмент собирается из исходных MP3-кадров. Точность реза — около 0.03 с.
- **Ничего не загружается на сервер.** Файл обрабатывается прямо в браузере, работает и офлайн.
- **Без установки.** Это один HTML-файл без зависимостей. Его можно скачать и открыть двойным кликом.
- Сохраняются теги (название, исполнитель, обложка), а длительность у VBR-файлов показывается правильно.

## Как пользоваться

1. Перетащите MP3 в окно или нажмите и выберите файл.
2. Выделите фрагмент мышкой прямо на волне. Края выделения можно тянуть.
3. Подправьте границы кнопками ±0.1 с / ±1 с: после каждой поправки сразу звучит этот край. Время можно ввести вручную: `1:23.5` или `83.5`.
4. Нажмите «Слушать фрагмент», чтобы проверить результат, и «Сохранить фрагмент», чтобы скачать файл.

Горячие клавиши: `Пробел` — слушать/стоп, `[` — начало там, где сейчас играет, `]` — конец там же.

## Как это работает

Утилита разбирает MP3 на кадры (каждый ~26 мс) и копирует в новый файл только кадры из выбранного промежутка. Тег ID3v2 переносится как есть. Заголовок Xing/Info переписывается под новую длину, а у VBR-файлов без заголовка он создаётся заново, чтобы плееры показывали правильную длительность. Для отображения волны и прослушивания используется Web Audio API.
